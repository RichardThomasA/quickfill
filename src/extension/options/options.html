Allowed Domains

Enter exact domains (e.g., google.com), one per line. Subdomains like mail.google.com will be ignored.

Import from JSON

Upload a JSON file with "texts" (array of {label, value}) and "allowedSites" (array of strings) to replace current settings. Example: {"texts": [{"label": "Greeting", "value": "Hello"}], "allowedSites": ["example.com"]}. See samples/sample.json for a complete example.
